# Consent Drift

Consent Drift is an Android app privacy-change analyzer that compares APK versions and highlights meaningful changes in permissions and privacy-sensitive capabilities.

## Project layout

- `backend/` – FastAPI service for the app API
- `analyzer/` – APK analysis and diffing work
- `frontend/` – UI/UX and app flows
- `docs/` – architecture and developer documentation
- `tests/` – project-level test notes and future integration tests
